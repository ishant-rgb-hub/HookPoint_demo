What it does

Everything you need for webhooks

Built using only Node.js native modules — no Express, no Axios, no bloat. Works out of the box with Node.js 18+.

🔁

Automatic Retries

Exponential, linear, or fixed backoff with randomized jitter. Respects Retry-After headers. Skips non-retryable errors automatically.

🔐

Cryptographic Signatures

HMAC-SHA256 signatures in Stripe/Svix format. Constant-time comparison via crypto.timingSafeEqual to prevent timing attacks.

🛡️

Replay Attack Protection

Configurable timestamp tolerance window. Each x-webhook-id is tracked — duplicate events are rejected within the cache TTL.

📊

Delivery Tracking

In-memory circular buffer storing full attempt history — status codes, latency, response snippets, timestamps, and real-time success rates.

📡

Fan-Out Dispatcher

Register multiple subscriber endpoints with wildcard topic matching (user.*, *). Concurrent delivery with aggregated summaries.

📥

Webhook Receiver

Drop-in handler for http.createServer. Verifies signatures, checks timestamps, deduplicates events — all in one call.

⚡

Zero Dependencies

Uses only node:http, node:https, node:crypto, node:events. No third-party packages, ever.

🟦

TypeScript Ready

Complete .d.ts type declarations included. Full IntelliSense support in VS Code and other IDEs with zero extra setup.

🧪

Fully Tested

Unit and integration test suite using native node:test. Run with npm test — no test framework needed.

Code Examples

Quick start

Three common patterns — each using only the hookpoint package.

const { sendWebhook } = require('@ishant3907/hookpoint');

async function deliver() {
  const record = await sendWebhook('https://api.partner.com/webhook', {
    event: 'order.placed',
    data: { orderId: 'ord_123', total: 99.50 }
  }, {
    secret: 'whsec_your_signing_secret',
    eventName: 'order.placed',
    retry: {
      maxRetries: 3,
      strategy: 'exponential',   // 'exponential' | 'linear' | 'fixed'
      initialDelayMs: 1000,
      jitter: true
    }
  });

  console.log(`Status: ${record.status}`);         // 'delivered' or 'failed'
  console.log(`Attempts: ${record.attemptCount}`);
}

deliver();
const { WebhookDispatcher } = require('@ishant3907/hookpoint');

const dispatcher = new WebhookDispatcher({
  defaultSecret: 'shared_secret_key'
});

// Register subscriber endpoints with event topic patterns
dispatcher.registerEndpoint({
  id: 'analytics-svc',
  url: 'https://analytics.internal/events',
  events: ['*']                        // receives ALL events
});

dispatcher.registerEndpoint({
  id: 'billing-svc',
  url: 'https://billing.internal/hooks',
  events: ['invoice.*', 'order.paid']  // wildcard matching
});

// Fan-out to all matching subscribers concurrently
const summary = await dispatcher.dispatch('order.paid', {
  orderId: 'ord_789',
  amount: 450.00
});

console.log(`Delivered: ${summary.delivered}/${summary.total}`);
const http = require('node:http');
const { WebhookReceiver } = require('@ishant3907/hookpoint');

const receiver = new WebhookReceiver({
  secret: 'whsec_your_signing_secret',
  tolerance: 300,        // 5-minute replay tolerance window
  replayProtection: true  // block duplicate event IDs
});

const server = http.createServer((req, res) => {
  if (req.url === '/webhook') {
    receiver.handle(req, res, async ({ event, payload, eventId }) => {
      console.log(`✓ Verified event: ${event}`, payload);
      // Process your business logic here...
      return { received: true };
    });
  }
});

server.listen(3000);
API Reference

Key exports

All exports from require('@ishant3907/hookpoint')

Export Type Description
sendWebhook(url, payload, opts) async fn Send a signed webhook POST with retries. Returns a full DeliveryRecord.
WebhookDispatcher class Register endpoints, match topics with wildcards, fan-out concurrently.
WebhookReceiver class Verify incoming webhooks — signatures, timestamp tolerance, replay protection.
DeliveryTracker class In-memory circular buffer. Query history, get stats, listen to events.
sign(payload, secret, opts?) fn Generate a t=...,v1=... signature header directly.
verify(raw, header, secret, opts?) fn Verify a signature header string. Returns { valid, reason }.
WebhookSignatureError class Custom error thrown on signature failure — includes code and reason.
